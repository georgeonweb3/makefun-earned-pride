One line, 1 to 240 characters, that gives the judge a quiet, earned moment of pride for someone in a scene. Free to enter, judged in pairs on genuine earned pride, a concrete scene, landing in one read and freshness.

The entry line (99 characters):

> The night guard who taught himself to read by torchlight finished the last page as the sun came up.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, no trailing newline).
